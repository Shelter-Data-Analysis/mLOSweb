mLOS: from a shelter export to results

Everything below runs inside this browser tab. The export is read here, prepared by ShelterDataPrep (Python), and analyzed by mLOS (R). Nothing is sent to a server.

Starting Python and R in the background...

Step 1

Load the export

A CSV file exported from the shelter's software, one row per stay. The demo file is the Mission Viejo Animal Services export (dogs and cats, 2016 to 2025).

Step 2

Match the columns

Each export names its columns its own way. Pick which column holds each piece of information. Guesses are filled in; check them against the preview above.

Step 3

Choose the date format

The page tries each format on every date in the three date columns. The right format reads all of them. When two formats both read every date, the file cannot tell them apart: check a date you know.

Step 4

Set the study window

The span of time to study, from its first day up to, but not including, its stop date. Every stay that overlaps it is kept, including animals already in care on the first day. The analysis later divides this window into periods.

Step 5

Define the age groups

Age at intake is computed from the date of birth. Each group runs up to and including its upper age; an animal older than the last group is dropped, and one with no date of birth is counted as _UNKNOWN_.

Group nameUp to age (years)

Leave a name blank to drop that row.

Step 6

Prepare the data

These choices become a ShelterDataPrep configuration file. The other rules (dogs only, and how this shelter's outcome and intake labels map to mLOS codes) are taken from the existing Mission Viejo configuration and stay fixed in this demo.

    Step 7
    
Run the analysis

    
mLOS compares periods within the study window. Add up to three dividing dates to split it into as many as four periods, and name each one. The slow features are turned off.
