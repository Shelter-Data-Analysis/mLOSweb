mLOS: from a shelter export to results

Everything below runs inside this browser tab. The export is read here, prepared by ShelterDataPrep (Python), and analyzed by mLOS (R). Nothing is sent to a server.

Starting Python and R in the background...

Step 1

Load the export

A CSV file or an Excel workbook (.xlsx or .xlsm) exported from the shelter's software, one row per stay, with the column names in the first row. The demo file is the Mission Viejo Animal Services export (dogs and cats, 2016 to 2025).

Already have a ShelterDataPrep configuration or an mLOS settings file?

Either file, or both, can stand in for the steps it covers: a configuration for steps 2 to 6, a settings file for the choices in step 8. Each runs as written, except for the changes the page lists, so a file this page wrote, or one prepared by hand for the programs on your own computer, gives the same results here.

Step 2

Match the columns

Each export names its columns its own way. Pick which column holds each piece of information. Guesses are filled in; check them against the preview above.

Step 3

Choose the animals

An analysis covers one species, so choose the column that names the species and the one to study. Then list any rows that are not shelter stays at all, such as animals dead on arrival, quarantine holds, or animals boarded for another agency. They are removed before anything else looks at the data.

Rows that are not shelter stays

Step 4

Choose the date format

The page tries each format on every date in the three date columns. The right format reads all of them. When two formats both read every date, the file cannot tell them apart: check a date you know.

Step 5

Set the study window

The span of time to study, from its first day up to, but not including, its stop date. Every stay that overlaps it is kept, including animals already in care on the first day. The analysis later divides this window into periods.

Step 6

Define the age groups

Age at intake is computed from the date of birth. Each group runs up to and including its upper age; an animal older than the last group is dropped, and one with no date of birth is counted as _UNKNOWN_.

Group nameUp to age (years)

Leave a name blank to drop that row.

Step 7

Prepare the data

These choices become a ShelterDataPrep configuration file. The other rules (the animal size labels) are taken from the existing Mission Viejo configuration and stay fixed in this demo. Outcome and intake labels pass through unchanged and are classified in step 8.

    Step 8
    
    Run the analysis
    
    
      
      
      Show the settings file as it will run
      
    
      
    
      Classify the outcomes
      
    
      Each outcome label in the prepared data, with the number of stays that end in it. Choose what each one means. Guesses are filled in where the label is a common one; every label needs a choice before the analysis can run.
      
    
      
    
      
    
      Group the intake types
      
    
      Each intake label in the prepared data, with its number of stays. Give each one a group name; labels with the same name are combined into one group, and the analysis compares the groups. Up to six groups. Tick "Leave out" to study only the other intakes.
      
    
      
    
    
      
    
      Set the periods
      
    
      mLOS compares periods within the study window. Add up to three dividing dates to split it into as many as four periods, and name each one. Choose the dates before looking at the results: at real events where there are any (a new program, a policy change), otherwise at calendar years or half-years. Aim for at least 100 outcomes in each period.

      Set the analysis horizon
      
    
      The longest stay the analysis follows (restricted_stay_cap). A stay that reaches it counts as in care up to that day, and nothing after it is used. Too low, and real long stays are cut short; too high, and a few mistaken records can dominate the averages. Start at 365 days, then check the fraction still in care at the horizon, which the results report after the run.
      
    
      
      
      
    
      
    
      
    
      Choose the reference groups
      
    
      Each hazard ratio compares a group with its reference. The largest group is usually the right one; choose another large group if the ratios come out extreme or their intervals very wide.
      
    
      
      
      
    
      
    
      
    
    
      
    
      
  
      

  
      
    Step 9
    
      Build the slide deck and its tables
      
    
      This step runs a second program, the deck builder mlos_review, which comes with mLOS and reads the analysis results. It writes a PowerPoint deck of findings and a workbook of the tables the deck draws on. On your own computer the same builder runs as python3 -m mlos_review.deck.
